# Nexthire Job Board

A modern AI-assisted job board application built with Next.js and Tailwind CSS.

## Features

- Browse job listings
- Search jobs instantly
- Dynamic job details page
- Responsive UI
- Clean modern design
- Fast performance
- Mobile-friendly layout

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel Deployment
